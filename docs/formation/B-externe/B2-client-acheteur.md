# B2 — Client acheteur

Public : entreprises cherchant à acheter un véhicule industriel via Wilmet. Durée de formation recommandée : 20 minutes.

## 1. Ce que le client acheteur peut faire

- Déposer une demande de recherche de véhicule.
- Suivre l'avancement de sa demande.
- Échanger avec son commercial Wilmet et recevoir des propositions.

Ce qu'il ne voit jamais : les vendeurs, les autres demandes, les prix d'achat de Wilmet.

## 2. Parcours d'entrée — formulaire public

Aucun compte n'est nécessaire pour démarrer. Depuis le site public, écran **Chercher un véhicule** :

1. Besoin : type de véhicule, marque et modèle souhaités, carrosserie.
2. Critères : année minimale, kilométrage maximal, configuration d'essieux, norme Euro, boîte.
3. Contexte : pays de livraison, ville, délai souhaité, **budget maximum en euros HT**.
4. Coordonnées : société, nom, e-mail, téléphone.
5. Envoi → page de remerciement et référence de demande (`WIL-BUY-…`).

Protection anti-spam et limitation de débit en place : une soumission normale passe instantanément, des envois répétés sont ralentis.

## 3. Suivi de la demande avec un compte

Après création de compte (type de partenaire = client), écran **Mes demandes** :

| Statut | Signification pour le client |
| --- | --- |
| Nouvelle | Demande reçue par Wilmet |
| Qualifiée | Besoin validé avec un commercial |
| En recherche | Wilmet sourcing des véhicules correspondants |
| Proposition envoyée | Un ou plusieurs véhicules proposés |
| Négociation | Discussion sur prix et conditions |
| Gagnée | Achat conclu |
| Perdue / Archivée | Demande close |

## 4. Ce que le client doit fournir pour aller vite

- Usage réel du véhicule (longue distance, chantier, distribution urbaine).
- Contraintes non négociables (hauteur, PTAC, hayon, boîte automatique).
- Budget maximum réaliste HT et mode de financement envisagé.
- Délai de mise en route et lieu de livraison.

## 5. Réception d'une proposition

1. Notification et statut « Proposition envoyée ».
2. Le commercial transmet la fiche du véhicule : caractéristiques, état, photos, documents disponibles, prix proposé HT, régime de TVA, disponibilité.
3. Le client répond : accord, contre-proposition ou refus motivé.
4. En cas d'accord, la demande passe en « Négociation » puis « Gagnée ».

## 6. Paiement

Le règlement est organisé par Wilmet : **acompte** puis **solde** avant livraison. Le paiement peut être effectué par virement ou via **PayCifi** (paiement sécurisé en séquestre : les fonds ne sont libérés qu'aux conditions prévues). Le suivi est assuré par le commercial.

## 7. Questions fréquentes des acheteurs

| Question | Réponse à donner |
| --- | --- |
| Puis-je voir tous les véhicules disponibles ? | Non, Wilmet propose une sélection ciblée à partir de votre besoin. |
| Combien de temps pour une proposition ? | Dépend du modèle recherché ; un besoin précis accélère fortement le sourcing. |
| Puis-je aussi vendre mes camions ? | Il faut un compte vendeur distinct. |
| Le véhicule est-il garanti sans gage ? | Oui, Wilmet contrôle le non-gage et la situation leasing avant achat. |
| Où sont les véhicules ? | Union européenne uniquement ; le pays est précisé dans chaque proposition. |

## 8. Checklist de fin de formation

- [ ] J'ai déposé une demande complète avec budget et délai.
- [ ] Je sais lire le statut de ma demande.
- [ ] Je sais répondre à une proposition.
- [ ] Je connais les étapes de paiement (acompte puis solde).
